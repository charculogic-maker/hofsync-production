# Glossar CharcuLogic / HofSync

Kurze, verbindliche Lesarten für Fachbegriffe in UI, Manuals und Marketing.

## WRS

**WRS** = **Wurst-Rezept-Skalierer**.

Werkzeug zum Hoch-/Runterrechnen einer Wurst-Rezeptur auf ein Zielgewicht (Chargenmasse), inkl. typischer Kennzahlen wie BEFFE, Selbstkosten und Marge.

| Kontext | Formulierung |
|---------|----------------|
| Erste Nennung / Titel | `WRS (Wurst-Rezept-Skalierer)` |
| Danach / Tabellen / Logs | `WRS` |
| Zusammensetzungen | `WRS-Kalkulation`, `WRS-Panel` |
| Vermeiden | `WRS-Skalierer`, `WRS Rezept-Skalierer`, `Rezeptur- & Chargen-Skalierer` als Alternativname |

Interne Code-IDs (`wrsState`, `#kitchen-wrs-panel`, …) bleiben unverändert.
