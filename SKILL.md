# Skill: Hofladen Documentation Generator

## Purpose

Monitors code changes in `web/` and backend logic, ensuring that the user guides `KOLLEGEN_ANLEITUNG_HOFLADEN_APP.md` and `ANLEITUNG_STEVESHOF.md` are perfectly synchronized with the actual application state.

## Core Rules & Constraints

1. **Device Constraint:** We explicitly use iPhones in the farm shop. Never, under any circumstances, use the word "Tablet" in the German documentation. Always use "Laden-iPhone" or "iPhone".

2. **Perspective:** Always write from the collective team perspective ("Wir-Perspektive"). Use terms like "unsere App", "wir scannen", "unser MHD-Monitor". Never address the team as "Ihr" or "Euch".

3. **Feature Tracking:** Keep a close eye on form fields. Ensure that changes like the new "Hersteller / Zusatz" text field or sticky category selections are immediately and accurately described in the Markdown manuals.
